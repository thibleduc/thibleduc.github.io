# Site LDH Studio

Site statique servi par GitHub Pages.

- `app-ads.txt` — vérification éditeur AdMob, doit rester à la racine.
- `index.html` — page d'accueil de l'éditeur.
- `stacked-cubes/privacy/` — politique de confidentialité (générée depuis `PRIVACY.md` du jeu).
- `stacked-cubes/support/` — page de support, à donner à Apple comme Support URL.
- `.nojekyll` — demande à GitHub de servir les fichiers tels quels.

Pour un nouveau jeu : ajouter un dossier `nom-du-jeu/` avec `privacy/` et `support/`.
